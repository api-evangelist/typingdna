# TypingDNA

TypingDNA provides AI-based typing biometrics authentication — recognizing people by how they type on desktop and mobile keyboards. Its RESTful Authentication API enrolls and verifies typing patterns for fraud prevention, account-sharing detection and passwordless second factors, while Verify 2FA replaces SMS/email one-time codes with typing verification, standalone or as an OIDC authentication method for Okta, Ping Identity and Microsoft Entra ID. Certified for ISO 27001, ISO 27017 and ISO 27018.

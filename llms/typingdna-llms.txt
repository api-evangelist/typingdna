# TypingDNA

> TypingDNA provides AI-based typing biometrics authentication: it recognizes users by how they type. Its RESTful Authentication API enrolls and verifies typing patterns, and its Verify 2FA product replaces SMS/email one-time codes with typing verification (standalone or as an OIDC authentication method for Okta, Ping Identity and Microsoft Entra ID). Certified for ISO 27001/27017/27018.

Generated by API Evangelist from apis.yml and the artifacts in this repository (no provider llms.txt was published as of 2026-07-21).

## APIs

- [Authentication API docs](https://api.typingdna.com/docs/index.html): Enroll and verify typing patterns (/auto, /save, /verify, /user, /changeuser) over HTTP Basic auth. Base URLs: https://api.typingdna.com, https://eu-api.typingdna.com, https://us-api.typingdna.com
- [Authentication API reference](https://api.typingdna.com/index.html): Rendered OpenAPI reference
- [Verify 2FA docs](https://verify.typingdna.com/docs/): Typing-verification 2FA with OTP Root-of-Trust fallback; OIDC issuer at https://verify.typingdna.com

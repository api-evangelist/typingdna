What is continuous authentication? Continuous authentication is a security solution that analyzes multiple data points linked to a unique user, including browser activity, mouse characteristics, mobile sensors, and behavioral biometrics. The data points are continuously monitored to identify changes in behavior, confirming or blocking a user’s access to corporate assets or programs.
